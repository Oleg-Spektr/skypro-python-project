## Зависимости
Проект использует следующие инструменты для контроля качества кода:
- **flake8**: проверка соблюдения стандартов PEP 8.
- **mypy**: статическая проверка типизации.
- **black**: автоматическое форматирование кода.
- **isort**: автоматическая сортировка импортов.

Все зависимости и их версии зафиксированы в файле `pyproject.toml`.

## Конфигурация и запуск
Для работы с проектом рекомендуется использовать виртуальное окружение.

1. **Установка зависимостей** (с помощью Poetry):
   ```bash
   poetry install
   ```

2. **Запуск линтеров**:
   Для проверки кода на соответствие стандартам выполните:
   ```bash
   flake8 homework/
   mypy homework/
   ```

3. **Автоматическое форматирование**:
   Чтобы привести код к единому стилю, используйте:
   ```bash
   isort homework/
   black homework/
   ```
