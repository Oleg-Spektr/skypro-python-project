# Виджет банковских операций

## Описание
Этот проект предназначен для фильтрации и сортировки банковских транзакций клиента. Он является частью виджета, который помогает пользователю отслеживать историю своих операций.

## Функционал
Проект содержит модуль `processing`, в котором реализованы две основные функции:
1. **`filter_by_state`** — фильтрует список транзакций по их статусу (например, `EXECUTED`, `CANCELED`).
2. **`sort_by_date`** — сортирует транзакции по дате (от новых к старым по умолчанию).

## Использование
Пример использования функций в коде:

```python
from homework.src.processing import filter_by_state, sort_by_date

data = [
    {'id': 414288290, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}
]

# Фильтрация по статусу
executed_data = filter_by_state(data, 'EXECUTED')

# Сортировка по дате
sorted_data = sort_by_date(data)
```
