## Тестирование

В проекте реализовано модульное тестирование с использованием фреймворка `pytest`. Написаны параметризованные тесты и применены фикстуры для проверки корректности работы функций, граничных случаев и обработки некорректных входных данных.

### Запуск тестов и проверка покрытия:
Для запуска тестов с выводом отчета о покрытии кода в терминал выполните команду:
```bash
python -m pytest tests/ --cov=. --cov-report=html
```

### Генерация HTML-отчета:
Для создания подробного визуального отчета о покрытии в формате HTML выполните:
```bash
python -m pytest tests/ --cov=. --cov-report=html
```
Отчет генерируется в папку `htmlcov/`. Чтобы посмотреть его, откройте файл `htmlcov/index.html` в любом браузере.


## Модуль `decorators` (Логирование работы функций)

Модуль предоставляет инструмент автоматического логирования выполнения функций с помощью декоратора `@log`.

### Основные возможности:
* Фиксация успешного старта и завершения функции с выводом `имя_функции ok`.
* Перехват и логирование ошибок с указанием типа исключения и всех входящих аргументов (как позиционных `args`, так и именованных `kwargs`).
* Поддержка вывода логов как в консоль (по умолчанию), так и в текстовый файл.

### Примеры использования:

```python
from src.decorators import log

# Логирование в файл
@log(filename="mylog.txt")
def my_function(x, y):
    return x + y

my_function(1, 2)  # Добавит в файл "mylog.txt" строку: my_function ok

# Логирование в консоль и обработка ошибок
@log()
def divide(x, y):
    return x / y

divide(1, 0)  # Выведет в консоль: divide error: ZeroDivisionError. Inputs: (1, 0), {}
```
